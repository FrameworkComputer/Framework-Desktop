## Designs

### Front Cover

[fw_desktop_front_cover.stl](fw_desktop_front_cover.stl) is the 3D design file
for the front cover.

The 3D file is mainly intented to help the community develop tiles that are compatible with the official front cover. It does not include magnets or the power button.
If you'd like to attach it to the Framework Desktop you need magnets of size 8.50x5.00x1.10mm. Eight of those are used in the product.
